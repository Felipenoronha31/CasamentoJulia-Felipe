PASTA DE IMAGENS DO SITE
========================

Coloque aqui as fotos do site. Os nomes dos arquivos precisam ser EXATAMENTE
estes (tudo minúsculo, com a extensão .jpg). Se usar .png, troque também no
script.js.

COMO SUBIR NO GITHUB
------------------------------------------------------------
1. No repositório, entre nesta pasta "img".
2. Add file > Upload files.
3. Arraste as fotos com os nomes acima.
4. Commit.
5. Abra o site e dê Ctrl + Shift + R para atualizar.

Se o nome do arquivo não bater com o do script.js, a foto não aparece.
Na galeria, uma foto que não existir é simplesmente ocultada (sem erro na tela).
